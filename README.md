# 🎸 Hitar

Приложение для смарт-часов (350×350 px), которое помогает гитаристам и укулелистам: определяет аккорды по расстановке пальцев на грифе, содержит встроенный тюнер с определением октавы и позволяет настраивать тональность.


## Ссыль

👉 [singularity1984.github.io/hitar](https://singularity1984.github.io/hitar/)

## 📋 Возможности

- **Интерактивный гриф** – нажимайте на лады, чтобы собрать аккорд. Приложение мгновенно определит его название.
- **Тюнер с октавой** – используйте микрофон для точной настройки гитары. Тюнер показывает ноту и октаву (например, A4).
- **Выбор инструмента** – гитара (6 струн) или укулеле (4 струны).
- **Каподастр** – виртуальное смещение тональности на ±5 полутонов.
- **Три кислотные темы** – зелёная (`#39ff14`), фиолетовая (`#b026ff`) и оранжевая (`#ff5e00`).
- **Адаптивная иконка** – соответствует гайдлайнам Google для Wear OS.

## 🧱 Че использовал чтобы вкусно было

- **React 18** (функциональные компоненты, хуки)
- **Vite** (сборка, минификация, обфускация)
- **SCSS** (препроцессор, переменные, миксины)
- **Atomic Design** (атомы → молекулы → организмы → страницы)
- **Web Audio API** (захват микрофона, анализ частоты)
- **GitHub Pages** (деплой)

- **Адаптивная иконка** – выполнена по гайдлайнам [Material Design](https://developer.android.com/guide/practices/ui_guidelines/icon_design_adaptive): круг 44×44 dp внутри холста 48×48 dp.
- **Тёмная тема и контрастность** – снижает энергопотребление на OLED‑экранах и соответствует требованиям [WCAG AA](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html) (контраст текста >10:1).
- **Минимум текста, иконки** – рекомендовано [Wear OS Design Principles](https://developer.android.com/training/wearables/design): пользователь должен понимать функцию мгновенно.
- **Отсутствие скролла** – вся важная информация (гриф) помещается на одном экране, что снижает когнитивную нагрузку.
